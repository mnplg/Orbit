# Orbit

一个常驻桌面的 macOS 小窗，帮助你同时记住正在进行、等待 AI、需人工、待你处理的任务。

## 使用

1. 双击 `Orbit.app` 打开。小窗会浮在其他窗口上方，并出现在所有桌面空间；菜单栏图标可显示、隐藏或退出。首次打开采用较紧凑的窗口高度；拖动窗口边缘可调整大小，位置和大小会在下次打开时恢复。任务过多时可在卡片区域滚动。
2. 点击“Orbit”标题旁的唯一加号，输入名称并回车新增主体任务。直接点击任务主体名称即可就地修改，按回车或点击其他位置保存；星标用于标记重要主体任务，`···` 菜单可修改状态或绑定会话。
3. 同一项目目录下的 Qoder、Cursor 和 Codex 会话会自动挂到一个主体任务中。分隔线下的会话框默认显示最后活跃的有效会话：第一行展示最后一次用户输入的最多 30 字预览，第二行右侧展示自动读取的会话名称。点击“展开全部”查看其他有效会话；展开后的会话按活跃时间从新到旧排列。任务组顶部星标用于标记主体任务和筛选，会话行提供打开、状态和移动等操作。
4. 普通会话超过 24 小时未更新后暂时隐藏，已完成会话也遵循此规则；置顶会话不受 24 小时限制。自动创建的项目分组在所有会话 7 天未更新后隐藏；记录仍保存在本机，后续更新会重新显示。
5. 点击主体任务名称可直接修改名称；点击主体任务状态摘要或左侧图标会打开其置顶会话，未置顶时选择最新有效会话。点击会话行会打开对应会话。
6. 标题区的星标按钮可切换“只看星标”，仅筛选主体任务自己的星标；会话的过期保留状态不影响筛选。点击任务组右侧的 `···` →“绑定会话”可以搜索已收集会话和 Codex“最近”里的旧任务，再组合进当前主体任务。超过 1 天未更新的旧任务绑定后会自动保留显示。会话右侧菜单可修改状态、移动到其他主体任务或移出主体任务。AI 回复明确要求你澄清问题或手动操作时，会话自动变为“需人工”；可在任务或会话菜单里手动修正。主体任务摘要中的会话数只统计当前状态的会话。
7. 程序每 5 秒同步本机已跟踪的 Cursor 对话。手动导入 Cursor 对话的入口已移除；既有 Cursor 会话继续同步。
8. 调色板可以切换“默认深色”“星夜电气”和“云白玻璃”；云白玻璃采用浅色渐变、半透明白卡片和蓝色强调。皮肤选择会自动记住。星夜电气的原创角色与云层插画随应用离线提供。
9. Qoder 会话会从本机最近 7 天的记录自动加入看板，之后继续每 5 秒同步。运行 `连接Qoder.command` 并重启 Qoder 后，还会接收官方 Hook 事件，帮助及时识别提交问题和回复结束。
10. Codex 会话会从本机最近 7 天的记录自动加入看板，之后继续每 5 秒同步。发送消息后显示“等待 AI”，回复结束后显示“待我处理”或“需人工”；点击 Codex 会话可直接跳转到对应任务。

任务数据只保存在本机的 `~/Library/Application Support/DeskFocusBoard/tasks.json`。这个内部目录名为兼容旧版而保留，改名升级不会重置任务数据。程序只读取本机 Cursor、Qoder 和 Codex 的会话记录，不会修改记录，也不会上传数据。Codex 读取 `~/.codex/state_5.sqlite` 中的任务元数据和 `~/.codex/sessions/` 中的状态事件。

## 适用范围

Cursor、Qoder 和 Codex 会话扫描已在本机记录格式上验证。Codex 桌面版支持通过 `codex://threads/<任务 ID>` 跳转到对应任务；其本地数据库格式可能随 Codex 版本变化。当前本机 Qoder 0.4.1 没有可验证的本地会话 ID 直达地址；没有手动保存的直达链接时，看板只能唤起 Qoder，不能自动选中准确会话。Qoder Hook 使用官方 `UserPromptSubmit` 与 `Stop` 事件；连接脚本会保留已有设置，并在修改前备份到 `~/.qoder/settings.json.deskfocus-backup`。Hook 只在本机保存会话 ID、项目目录、事件类型，以及用于任务标题的最多 90 个字符的提问预览，不上传对话。

## 重新构建

双击 `build.command`，或在终端执行 `./build.command`。需要 macOS 13 以上及 Swift 编译器。构建后生成同目录下的 `Orbit.app`。
