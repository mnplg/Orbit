macOS 本地工具

Orbit

当你同时等待多个 AI 编程会话时，用一个悬浮小窗记住当前正在做什么。

一、安装和启动

  1. 解压发布包，把 Orbit.app 拖到“应用程序”或其他你喜欢的位置。
  2. 第一次打开如果 macOS 提示无法验证开发者，请在 Finder 中对应用按住 Control 点击 → 打开 → 打开。这是未提交公证的本地应用常见提示。
  3. 启动后会出现一个常驻桌面的小窗。它会浮在其他窗口上方，也可以从菜单栏图标显示、隐藏或退出。任务卡片采用紧凑布局；拖动窗口边缘可一次看到更多任务组，调整后的位置和大小会自动记住；任务较多时可在卡片区域滚动。
任务数据保存在当前用户本机，不会上传到服务器。

二、自动识别 AI 会话

Qoder

双击发布包里的 连接Qoder.command，按提示连接 Hook，然后重启 Qoder。任务板会按项目目录自动归组。

Cursor

任务板会读取当前用户已跟踪的 Cursor 本地记录。首次使用后等待几秒，最近会话会出现在对应项目组里。

Codex

任务板会读取本机最近七天的 Codex 任务，并按项目目录归组。发送消息后显示“等待 AI”，回复结束后显示“待我处理”；点击会话可跳转到 Codex 中对应的任务。

主体任务下可以挂多个会话。最近活跃的会话会显示在最上方；每条会话第一行是最后一次由你输入的内容（最多 30 字，超出显示省略号），第二行右侧是会话名称。展开后按活跃时间从新到旧排列。超过一天未更新的会话会隐藏，项目分组超过七天没有更新也会隐藏。

三、日常操作

  • 点击主体任务的名称可修改名称；点击状态摘要或左侧图标，以及点击会话行，可以尝试打开对应的 AI 编程窗口。会话名称由本地会话自动提供。
  • 标题旁的 + 新增主体任务；直接点击主体任务名称即可就地修改，按回车或点击其他位置保存。星标用于标记重要主体任务，任务组右侧菜单用于修改状态和绑定会话。
  • 点击任务组顶部的星标，把主体任务加入星标筛选。标题区的星标按钮可以切换“只看星标”。
  • 打开主体任务右侧的 ··· 菜单，选择“绑定会话”，可以搜索 Qoder / Cursor / Codex 会话，也能找到 Codex 左侧“最近”里的旧任务。超过一天未更新的旧任务绑定后会自动保留显示；会话菜单中的“移出主体任务”可以撤销归组。
  • AI 回复明确要求你澄清问题或手动操作时，会话会自动显示“需人工”；如果识别不准确，可在任务或会话右侧的 ··· 菜单里手动修改。主体任务摘要里的会话数只统计当前状态对应的会话。
  • 点击调色板按钮，可以切换“默认深色”“星夜电气”和“云白玻璃”皮肤。云白玻璃使用浅色渐变、半透明白卡片和蓝色强调；星夜电气的角色与云层插画包含在应用里，离线也能显示。选择会自动记住。

四、数据和权限

任务数据位置：~/Library/Application Support/DeskFocusBoard/tasks.json。这个内部目录名为兼容旧版而保留，升级为 Orbit 不会重置任务数据。程序只读取本机的 Cursor / Qoder / Codex 会话记录，并保存任务状态、项目归组和必要的 Hook 事件信息。Codex 的本地记录位于 ~/.codex/；记录格式可能随 Codex 版本变化。

换电脑时，任务数据不会随应用自动迁移；如果需要保留任务，可在旧电脑复制整个 DeskFocusBoard 文件夹到新电脑同一位置。

五、常见问题

启动后没有会话

确认 Cursor、Qoder 或 Codex 已经产生本地会话；Qoder 需要先运行连接脚本并重启。任务板每 5 秒同步一次，也可以退出后重新打开。

应用被 macOS 拦截

不要直接双击反复尝试，请在 Finder 中 Control 点击应用，选择“打开”。如果公司电脑有安全策略，请联系管理员允许本地未签名应用。

窗口不见了

点击菜单栏里的任务板图标，选择“显示任务板”。

如何更新

退出旧版本，把新版本应用替换进去。任务数据在 Application Support 中，正常更新不会删除。
