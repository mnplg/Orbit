# Task card density

## Requirements

### Compact task groups

The board SHALL arrange the subject task pin and menu controls horizontally and reduce unused vertical spacing around a task group and its preview conversation.

#### Scenario: several active groups

- **WHEN** the board shows several active subject tasks in a 619-point-high window
- **THEN** at least three typical task groups are fully visible without shrinking action hit areas

### Window size

The board SHALL start at a screen-bounded height no greater than 700 points on first launch and SHALL restore a previously saved user window frame.
