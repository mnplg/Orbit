# Design

- Clicking a subject task name replaces the label with a focused text field.
- Pressing Return or clicking anywhere outside the field commits a non-empty trimmed name. Escape cancels the edit.
- Remove the task menu's edit entry and the next-step/link fields. Keep legacy stored fields decodable for existing task files.
- Remove the session menu's edit entry and its name/link form. Session names remain sourced from the conversation integration.
