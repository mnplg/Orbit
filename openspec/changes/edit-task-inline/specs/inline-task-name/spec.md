# Inline task name editing

## Requirements

### Edit a subject task name in place

The board SHALL turn a subject task name into a focused text field when the name is clicked. It SHALL save a trimmed non-empty value on Return or when focus leaves the field, and SHALL cancel on Escape.

### Remove unused editing forms

The task menu SHALL not expose an edit form for next-step or related-link fields. The conversation menu SHALL not expose a session edit form.
