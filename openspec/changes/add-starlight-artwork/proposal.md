# Proposal

## Why

“星夜电气”目前主要靠颜色和系统图标表现，与参考图中的角色和夜空装饰仍有明显差距。图片素材现在可用，可以给这套皮肤加入完整的视觉层次。

## What Changes

- 生成原创的发光小云朵角色和夜空云层素材。
- 在星夜电气皮肤的顶部和底部展示素材。
- 将素材纳入应用构建和发布压缩包。

## Capabilities

### New Capabilities
- `starlight-artwork`: 星夜电气皮肤的本地插画与背景装饰。

### Modified Capabilities

## Impact

- 新增 `Assets/` 两张 PNG 素材。
- 修改 `Sources/main.swift` 和 `build.command`。
