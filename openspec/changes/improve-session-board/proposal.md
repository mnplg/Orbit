# Proposal

## Why

同一主体任务下的会话增多后，看板会被旧会话占满，且从气泡回到原会话需要重新查找。需要让当前会话保持醒目，同时保留可展开的上下文和可靠的导航入口。

## What Changes

- 每个主体任务默认只显示最近更新的有效会话，按需展开所有有效会话；会话可单独置顶。
- 超过 24 小时没有更新的普通会话暂不展示，已完成会话也遵循该时间；置顶会话不受此限制。自动创建的项目分组在所有会话 7 天未更新后隐藏，不删除本机记录。
- 主体任务与会话气泡提供点击导航；无可靠原会话地址时明确提示，并允许为会话保存可直达的链接。
- 精简分组信息，让主体任务名右对齐，会话行保持完整内容和统一对齐。
- 移除“跟踪 Cursor 对话”的手动导入入口，继续同步已跟踪的 Cursor 会话。

## Capabilities

### New Capabilities

- `session-visibility`: 会话排序、置顶、折叠与过期展示规则。
- `session-navigation`: 气泡点击后的原会话定位和失败提示。
- `board-presentation`: 主体任务与会话的布局及 Cursor 导入入口。

### Modified Capabilities

无。

## Impact

`Sources/main.swift` 的本地数据模型、轮询更新、分组筛选、卡片 UI 与窗口导航；`README.md` 的使用说明。本地 `tasks.json` 保持向后兼容。
